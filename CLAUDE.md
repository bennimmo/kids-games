# Notes for Claude

## Going live
- The owner wants finished work to go live straight away, every time.
- When a change is done and tested: merge the latest `main` into your branch, push your branch, then push it to `main` (`git push origin HEAD:main`). No pull request needed, no need to ask.
- Every push to `main` deploys to GitHub Pages.
